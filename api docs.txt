1. EXECUTIVE API ARCHITECTURE & CONVENTIONS
===============================================================================

1.1 URL Conventions & Aliasing:
  - Master Base URL: `/api/`
  - Subsystems are organized under distinct modular prefixes:
    * `/api/auth/`            -> User identity, multi-identifier login, JWT, OTP
    * `/api/photographers/`   -> Studio profile, watermark branding, feed, notifications
    * `/api/subscriptions/`   -> Tiered plans, quotas, billing upgrades
    * `/api/storage/`         -> Enterprise galleries, direct uploads, proofing, downloads
  - Backward-compatibility aliases are preserved at the root level:
    * `/api/galleries/`       -> maps directly to `/api/storage/galleries/`
    * `/api/events/`          -> maps directly to `/api/storage/events/`
    * `/api/share/`           -> maps directly to `/api/storage/share/`
    * `/api/account/storage/` -> maps directly to `/api/storage/account/storage/`

1.2 Request & Response Formats:
  - All JSON payloads must be sent with `Content-Type: application/json`.
  - Multipart payloads (avatars, watermark stamps, manual uploads, selfies) must
    use `Content-Type: multipart/form-data`.
  - Datetimes are formatted in ISO-8601 UTC (e.g., `2026-09-12T12:00:00Z`).
  - IDs: User & Photographer IDs are Integers; Galleries, Media, Selections,
    Reservations, and Bulk Jobs use UUID v4 strings.

1.3 Authentication Header:
  - Format: `Authorization: Bearer <access_token>`
  - Access tokens have a 60-minute lifespan; refresh tokens have a 1-day lifespan.

12.2 Standard Error Response Payload:
When any API call encounters an error, a structured JSON payload is returned:
  {
    "code": "ERROR_CODE_STRING",
    "detail": "Human-readable explanation of why the request failed."
  }

Common Error Codes:
- 400 VALIDATION_ERROR: Missing required fields or malformed payload.
- 401 AUTHENTICATION_REQUIRED: Missing or expired JWT Bearer token.
- 403 GALLERY_ACCESS_DENIED: Gallery is private or password required.
- 403 DOWNLOAD_DISABLED: Studio has disabled downloads for this gallery.
- 403 FACE_SEARCH_DISABLED: Biometric face search is toggled off.
- 404 NOT_FOUND: Gallery, media item, or job ID does not exist.
- 410 LINK_EXPIRED: The requested cryptographic share token has expired.
- 413 STORAGE_LIMIT_EXCEEDED: Requested upload exceeds subscription storage limit.
- 429 RATE_LIMIT_EXCEEDED: Scoped throttle threshold exceeded; retry after backoff.
