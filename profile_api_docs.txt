2. UPDATE PERSONAL INFORMATION (SAVE CHANGES)
===============================================================================
Endpoint: PATCH /api/photographers/profiles/me/
Alternative Aliases:
  - PUT   /api/photographers/profiles/me/
  - PATCH /api/photographers/profiles/me/patch/
  - PUT   /api/photographers/profiles/me/update/
Auth Required: Yes (Photographer Bearer Token)
Content-Type: application/json

Description:
  Updates personal details displayed in the "Personal Information" card.
  * Note on Automatic User Synchronization:
    - Updating 'name' updates PhotographerProfile.name AND User.fullname.
    - Updating 'phone' updates PhotographerProfile.phone AND User.phone.
    - Updating 'email' updates PhotographerProfile.email AND User.email.

Request Body (JSON):
{
  "name": "Sarang A",
  "phone": "+918129886279",

  "occupation": "Wedding & Editorial Photographer"

3. UPLOAD / UPDATE PROFILE PHOTO (AVATAR)
===============================================================================
Endpoint: POST /api/photographers/profiles/me/avatar/
Auth Required: Yes (Photographer Bearer Token)
Content-Type: multipart/form-data

Description:
  Uploads a new profile image. Powers the "Upload Image" button.
  Recommended: Square image, at least 500x500px (JPEG, PNG, WebP).

Request Body (Form-Data):
  avatar: <binary image file>

Response (200 OK):
{
  "message": "Avatar uploaded successfully",
  "avatar_url": "http://127.0.0.1:8000/media/photographer_profiles/avatar.jpg",
  "data": {
    "id": 8,
    "name": "Sarang A",
    "avatar_url": "http://127.0.0.1:8000/media/photographer_profiles/avatar.jpg"
  }
}

Error Responses:
  - 400 Bad Request:
    { "message": "No image file provided in 'avatar' field." }
  - 401 Unauthorized:
    { "message": "Authentication required." }

4. REMOVE PROFILE PHOTO
===============================================================================
Endpoint: DELETE /api/photographers/profiles/me/avatar/
Auth Required: Yes (Photographer Bearer Token)

Description:
  Deletes the current profile photo and resets avatar fields.
  Powers the "Remove" button in the Profile Photo card.

Request Headers:
  Authorization: Bearer <access_token>

Response (200 OK):
{
  "message": "Profile photo removed successfully",
  "avatar_url": "",
  "data": {
    "id": 8,
    "name": "Sarang A",
    "avatar": null,
    "avatar_url": "",
    "profile_image": null
  }
}

Error Responses:
  - 401 Unauthorized:
    { "message": "Authentication required." }
  - 404 Not Found:
    { "message": "Photographer profile not found." }

FRONTEND INTEGRATION EXAMPLES (JAVASCRIPT / AXIOS)
===============================================================================

// 1. Fetch Profile Data
const fetchProfile = async () => {
  const response = await axios.get('/api/photographers/profiles/me/', {
    headers: { Authorization: `Bearer ${token}` }
  });
  const profile = response.data;
  console.log('Quick Info:', profile.quick_info);
  console.log('Plan:', profile.plan_details);
};

// 2. Save Personal Information
const savePersonalInformation = async (formData) => {
  const response = await axios.patch('/api/photographers/profiles/me/', {
    name: formData.name,
    phone: formData.phone,
    email: formData.email,
    occupation: formData.occupation
  }, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data;
};

// 3. Upload Avatar
const uploadAvatar = async (file) => {
  const formData = new FormData();
  formData.append('avatar', file);
  const response = await axios.post('/api/photographers/profiles/me/avatar/', formData, {
    headers: { 
      Authorization: `Bearer ${token}`,
      'Content-Type': 'multipart/form-data'
    }
  });
  return response.data.avatar_url;
};

// 4. Remove Avatar
const removeAvatar = async () => {
  const response = await axios.delete('/api/photographers/profiles/me/avatar/', {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data;
};
